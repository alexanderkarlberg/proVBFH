The structure of the data is xlow xhigh sigma/(xhigh-xlow) error/(xhigh-xlow)

Each STXS bin on its own, with a name that identifies the bin. eg

STXS-MJJ-350-700-PTH-0-200-PTHJJ-0-25-DPHIJJ-PIov2-PI

is the STXS bin with 350 < mjj < 700, 0 < ptH < 200 and π/2 < δφjj < π

All the 2D distributions are 1D differential distributions binned in
one variable. For instance

HISTO-MJJ-PTH-120-260-PTJ-20

is the 120 < ptH < 260 bin differential in MJJ for jets of ptj > 20.  


At NNLO scale variations ahve also been computed.
nnlo-central.top: Contains the central prediction
nnlo-max.top: Contains the upper band
nnlo-min.top: Contains the lower band
